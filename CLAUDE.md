# Claude Code Context: scripts

## Repository Purpose
Public collection of generic development utility scripts. These are vanilla tools useful for any developer.

**Important:** This is a public repository. Never add proprietary or company-specific information.

## Scripts

### git.sh
Git workflow reference covering:
- Rebase and branch management
- Squashing commits
- Co-authoring with collaborators
- Fork synchronization
- Word diffs and patch generation

### git-pull-all.sh
Batch git pull across multiple repositories in subdirectories.

### cli.sh
Simple CLI utilities:
- SHA-256 checksum generation with OpenSSL

## Usage
These are reference files, not executable scripts. Copy commands as needed.

## Adding New Scripts
When adding scripts, ensure they:
1. Contain no proprietary references
2. Are useful to the general developer community
3. Include comments explaining usage
